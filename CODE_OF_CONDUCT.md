# Code of conduct

ragcourt follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, criticise ideas and code rather than people, and help newcomers.

Report unacceptable behaviour privately to the maintainer through the contact on the maintainer's GitHub
profile. Reports are kept confidential.
